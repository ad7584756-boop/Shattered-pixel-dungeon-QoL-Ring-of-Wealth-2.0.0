# Build the 1.0.6 debug APK with GitHub Actions

1. Download and extract the complete source ZIP.
2. Create a GitHub repository (or use your existing repository) and upload/commit the extracted project contents, including the `.github/workflows` folder.
3. Push the commit to the repository's default branch.
4. Open the repository's **Actions** tab.
5. Select **Build Android APK (debug)**.
6. Press **Run workflow** and confirm the default branch.
7. When the run finishes successfully, open the run and download the artifact named `shattered-pixel-dungeon-qol-1.0.6-debug-apk`.

This workflow creates a debug APK. It is not a signed Play Store/release APK.
